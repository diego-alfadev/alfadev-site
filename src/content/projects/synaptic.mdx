  <b>A brain for your AI agent.</b> Useful knowledge that survives the chat.

Every new chat with a coding agent starts from zero. You explain the project again, or the agent guesses. Synaptic keeps decisions, lessons and playbooks in linked Markdown files you own, so a fresh session, a different agent or another person can pick the work up from them.

## What it gives you

- **Plain Markdown.** Read it, edit it, diff it and version it with the tools you already use.
- **Bounded reading.** One short boot file, an index, and small notes the agent opens only when it needs them.
- **Any agent.** It works with any agent that can read and write files.
- **Global or per project.** A brain is always the same folder; what changes is where you connect it.
- **Paste-to-install.** You install it by pasting one prompt into your agent.

## What it does not do

It is not a database or a graph engine, and it does not curate knowledge on its own. Curation happens when you ask for it.

## Where it comes from

The pattern comes from Karpathy's LLM-wiki idea, and it owes a lot to [Engram](https://github.com/Gentleman-Programming/engram) and [gentle-ai](https://github.com/Gentleman-Programming/gentle-ai). It is MIT licensed.

The quickstart is in the [repository README](https://github.com/diego-alfadev/synaptic-core#quickstart).

<section class="prose-base text-text mb-8" >
  <b>Un cerebro para tu agente de IA.</b> Conocimiento útil que sobrevive al chat.

Cada chat nuevo con un agente de código empieza de cero. Vuelves a explicar el proyecto, o el agente se lo inventa. Synaptic guarda decisiones, lecciones y procedimientos en archivos Markdown enlazados que son tuyos, así que otra sesión, otro agente u otra persona pueden retomar el trabajo desde ahí.

## Qué te da

- **Markdown plano.** Se lee, se edita, se compara y se versiona con las herramientas que ya usas.
- **Lectura acotada.** Un archivo de arranque corto, un índice y notas pequeñas que el agente abre solo cuando las necesita.
- **Cualquier agente.** Funciona con cualquier agente que lea y escriba archivos.
- **Global o por proyecto.** Un cerebro es siempre la misma carpeta; lo que cambia es dónde lo conectas.
- **Se instala pegando un prompt.** Pegas un prompt en tu agente y él hace el resto.

## Qué no hace

No es una base de datos ni un motor de grafos, y no cura el conocimiento solo. Lo hace cuando se lo pides.

## De dónde viene

El patrón parte de la idea del LLM-wiki de Karpathy y le debe mucho a [Engram](https://github.com/Gentleman-Programming/engram) y [gentle-ai](https://github.com/Gentleman-Programming/gentle-ai). Tiene licencia MIT.

El arranque rápido está en el [README del repositorio](https://github.com/diego-alfadev/synaptic-core#quickstart).
